# 独立评审（Reviewing Independently）

## 概述

中/高复杂度的子任务在验收前，由独立评审把关：评审者不读实现者的对话/报告，只读代码、契约、验收标准，输出分级问题清单。

## 根本原则

**执行与评审永不兼任。** 评审者读了实现者上下文 = 评审失效。

## 何时使用

- 中/高复杂度子任务已实现、测试通过，验收之前
- 需要独立于实现者判断"是否真的符合契约与验收标准"

**何时不用**：低复杂度——自评即可，不做独立评审。

## 评审依据

1. 接口契约（逐条一致：签名 / 数据模型 / 错误码）
2. 需求对话产出的验收标准
3. 代码 diff 与相关文件

## 问题分级

- **阻塞**：不修不能合入（契约不符、安全漏洞、AC 不满足）
- **建议**：应修，可合入后跟进
- **可选**：吹毛求疵，不修也行

## 结论

通过 / 需修改（有阻塞） / 否决（根本性问题需重新设计）

## 常见错误 / 红旗

- 评审者读取实现者的对话上下文（独立性失效）
- "感觉不对"式意见，没有具体位置/契约条目
- 为了礼貌放行，或为了显得严格吹毛求疵
